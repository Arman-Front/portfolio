# Портфолио — Vue 3 + Vite

Портфолио-сайт на чистом Vue 3 (без Nuxt), собранный Vite.

## Структура

- `src/App.vue` — сборка всех секций
- `src/components/` — компоненты (TabBar, ThemeToggle, секции, MediaRow, Lightbox)
- `src/composables/` — переключение темы, scroll-spy табов, состояние лайтбокса
- `src/data/experience.js`, `src/data/petProjects.js` — контент карточек опыта/pet-проектов
- `src/assets/img/` — скриншоты проектов (импортируются как модули, Vite сам их оптимизирует/хэширует)
- `src/style.css` — все стили (перенесены из исходной HTML-версии один в один)

## Запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build     # продакшн-сборка в dist/
npm run preview   # предпросмотр собранной версии
```

## Что перенесено из HTML-версии

- Тема light/dark с плавным переключением
- Scroll-spy для таббара с центрированием активного таба
- Построчная нумерация в about.md (считается по реальным строкам текста через Range API)
- Галереи с fade-затенением краёв при скролле
- Лайтбокс с свайпами, стрелками и точками пагинации
